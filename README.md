# Практическая работа №6

## Тема
Многопоточность, синхронизация потоков и условные переменные.

## Задание 1
Реализованы две версии производителя и потребителя:
- producer_semaphore.py — два семафора и мьютекс;
- producer_condition.py — мьютекс и условная переменная.

Параметры:
- 3 производителя;
- 2 потребителя;
- кольцевой буфер на 5 элементов;
- 1000 элементов.

`queue.Queue` не используется.

## Задание 2
Проверяется количество произведённых и потреблённых элементов,
а также соответствие наборов элементов и нарушения работы буфера.

Ожидаемый результат: PASS.

## Задание 3
barrier_demo.py демонстрирует барьер для четырёх потоков,
выполняющих три фазы работы.

## Задание 4
lost_wakeup.py демонстрирует использование условной переменной
и объясняет риск использования if вместо while.
